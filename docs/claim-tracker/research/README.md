# Claim research queue

These are authored public-source research briefs for the planned community claim tracker. They are review material, not published pilot assessments or member submissions. They contain no private submission links, member identities, or personal travel records.

The tracker remains a documentation proposal in [draft PR #6](https://github.com/ExtiVaries/How-to-Hear-a-Bully/pull/6). Adding a brief does not launch that system, assign a human reviewer, enable monitoring, or clear its remaining design and release checks. A designated reviewer must verify the circulating assertion, sources, scope, and current status before adopting an assessment. These files are not an approved import schema.
