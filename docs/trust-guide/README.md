# Who to Trust When It All Breaks Down?

*A practical guide to conflicting claims, expertise, and uncertainty.*

Research and drafting packet · 9 October 2026 · **In development**

This is the next proposed guide in the Practical Guides collection. It helps readers decide whom to rely on for a particular question when familiar sources disagree. The title describes a loss of orientation; it does not claim that every institution has failed.

## Start here

Open **[the complete Claude handoff](claude-complete-handoff.md)**. It contains the drafting prompt, editorial brief, source ledger, two fictional exercises, and review checklist in one file. Download the raw Markdown or copy its contents into Claude. No other attachments are required.

Suggested message:

> Use this complete handoff to write the first draft of *Who to Trust When It All Breaks Down?* Return the guide, linked source notes, and candid handoff report requested in the packet. Check the evidence rather than treating the brief as infallible. Do not publish yet.

The next step is a concrete draft and then an independent review. The five questions are an editorial teaching aid, not a tested trust score. This packet reflects a targeted source check, not a systematic literature review or human reader testing.

These files are research material on a development branch. They do not add a guide to the live collection. Reuse terms for this new material have not been chosen; the Bully guide's license does not automatically apply.
